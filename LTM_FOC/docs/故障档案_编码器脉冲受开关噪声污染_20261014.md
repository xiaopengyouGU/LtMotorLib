# 故障档案：增量编码器脉冲受 PWM 开关噪声污染导致换相异常


| 项目 | 内容                                                                                        |
| ---- | ------------------------------------------------------------------------------------------- |
| 编号 | FA-2026-1014-01                                                                             |
| 日期 | 2026-10-14                                                                                  |
| 平台 | RA6M4（R7FA6M4AF）+ LTM_HAL(RA6M4) + LTM_FOC + LTM_CTRL                                     |
| 对象 | 100W/24V 40 机座伺服电机，12 槽 10 极（PP=5），2500 线增量编码器（10000 CPR）               |
| 结论 | 编码器 A/B 脉冲在功率级开关瞬间被污染，GPT 将振铃边沿计入计数，换相角被破坏；与控制算法无关 |

---

## 1. 摘要

转矩模式给定恒定电流，电机起动后力矩逐渐衰减并停住，加大到 0.6/0.7A 仍无法重启；正反行为
不对称。所有环路内部量（位置、速度、Id/Iq）互相一致，无越限、无保护动作。

换相角 `the` 由编码器计数导出。计数被污染后电流矢量偏离真实 q 轴，轴上力矩按 `cosΔ` 衰减。
位置与速度同源，互相比对无法发现该错误；速度环靠加大电流掩盖损失，仅转矩模式（开环电流
给定）暴露。

GPT 输入滤波由关闭改为 PCLK/4：−3000RPM 维持电流由 1.25A 降至约 0.5A，力矩漂移停止。
改为 PCLK/16：60s 内多圈位置跳变由 1 次降为 0 次，稳态电流波动由 19% 收敛至 ±0.01A。

## 3. 现象

1. **转矩模式**：T=0.3A 起动后加速到约 40RPM，0.2~2s 内减速停住；三相电流变为直流
   （0.44/0.135/−0.575A），电流矢量静止于估计 q 轴。停住后增至 0.6/0.7A 仍无法重启，需重新上电。
2. **方向不对称**：T=±0.4A 行为不对称；个别次上电后起动方向与指令相反。
3. **速度模式**：+3000RPM 连续 5min 正常；−3000RPM 数秒后失步并触发过速/欠压。同转速维持
   电流不对称：+3000 约 0.56A，−3000 约 1.25A。
4. **上报量自洽**：位置微分与上报速度同源一致；Id≈0、Iq 等于给定、母线稳定、无保护触发。

## 4. 排查

### 4.1 已排除项


| 怀疑方向                           | 排除依据                                                                                           |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| 负载/摩擦                          | 空载。由 J·α 反解：0.3A 时驱动力矩约 6e-5N·m、阻力约 4e-5N·m，阻力不足以顶住 0.3A              |
| 电流采样                           | 三相电流幅值与给定一致，Ia+Ib+Ic=0，电流钳实测吻合                                                 |
| 零点偏置被改写                     | `zero_offset` 仅一处写入（`control_tasks.c:147`，预定位内），仅一个调用者（`lt_motor.c:72`，上电） |
| 计数器被复位                       | 全库检索，`ltm_enc_set_zero()` 在 FOC 工程内无调用者                                               |
| 斜坡规划器 / PLL / 解耦 / PID 限幅 | 逐项读码与注入试验                                                                                 |

### 4.2 有效力矩

换相角无速度项（`ANGLE_DELAY_STEP=0`，`the_park = (count − zero_offset)×PP`），轴上力矩

τ = Kt·Iq·cosΔ,   Δ = the_park − θ_rotor
由位置二阶差分反解（J 取铭牌值）：


| 段              | 加速度       | 推算力矩       | 占指令比例                |
| --------------- | ------------ | -------------- | ------------------------- |
| 0.3A 起步加速段 | ~3.5 rad/s² | 净 2.1e-5 N·m | —                        |
| 停车减速段      | ~17 rad/s²  | 净 1.0e-4 N·m | —                        |
| 解出驱动力矩    | —           | ≈6e-5 N·m    | 0.2%（指令 1.09e-2 N·m） |
| 解出阻力矩      | —           | ≈4e-5 N·m    | 空载量级                  |

±0.35A 反相瞬态：147RPM 变化耗时 0.93s，α≈16.5 rad/s²，驱动力矩与摩擦同向叠加，
τ_drive ≤ 9.7e-5 N·m，即 ≤ 指令的 0.8%。

`|Δ|` 已达 89° 量级，电流几乎全部落在真实 d 轴，只产生磁吸，不产生平均转矩。

### 4.3 内部自洽为何失效

位置、速度、Id/Iq 均由同一计数导出，计数被污染时三者仍互相一致。用同一传感器数据互相
验证的检查无法发现该故障，必须引入不同源参照。

---

## 5. 根因

编码器信号链为"差分 → 单端模块 → 杜邦线 → MCU 引脚"，杜邦线紧贴三相输出端子，模块输入端
未做差分终端匹配。功率级开关瞬间的振铃被模块接收并在输出端形成边沿串，GPT 输入滤波默认
关闭，边沿全部计入计数。污染分两类：

1. **密集小毛刺**：计数相对转子缓慢累积偏差，Δ 随行程漂移，力矩按 cosΔ 平滑衰减，最终在
   Δ≈90° 处锁死。角度链无速度项，与转速无关，低速同样出现。
2. **稀疏大脉冲串**：单次可计入数万计数，多圈位置重建被破坏。实测一次跳变 27986 counts
   （≈2.8 圈）；该值接近一个电周期（2000 counts）的整数倍时电角度几乎不变，速度环无感。

## 6. 措施与实测效果

### 6.1 软件：GPT 输入噪声滤波

滤波档位经 `GTIOR.NFAEN/NFCSA`、`NFBEN/NFCSB` 配置（FSP 字段 `capture_filter_gtioca/b`），
A/B 同档以避免差分偏斜。


| 设置    | 采样周期 | 可抑制振铃                 | 边沿延迟 | 安全转速上限（10000CPR） |
| ------- | -------- | -------------------------- | -------- | ------------------------ |
| 关闭    | —       | —                         | —       | —                       |
| PCLK/4  | 40.4ns   | 半周期 ≲80ns（≳6MHz）    | ~120ns   | ~49000RPM                |
| PCLK/16 | 161.6ns  | 半周期 ≲320ns（≳1.5MHz） | ~485ns   | ~12400RPM                |
| PCLK/64 | 646ns    | ≲1.3µs                   | ~1.94µs | ~3100RPM，不可用         |

PCLK/16 代价：3000RPM 下边沿延迟折合 0.009° 机械角、0.044° 电角；安全上限仍有 4 倍余量。
PCLK/64 的判据窗 1.94µs 与 3000RPM 时的正交计数间隔 2µs 同量级，会吞掉真实边沿。

寄存器现场（R_GPT4 @ 0x40169400）：


| 寄存器        | PCLK/4        | PCLK/16       | 说明                                 |
| ------------- | ------------- | ------------- | ------------------------------------ |
| GTIOR (0x34)  | 0x60006000    | 0xA000A000    | NFAEN/NFBEN=1，NFCSA/NFCSB=0b01/0b10 |
| GTPR (0x64)   | 0x0000270F    | 0x0000270F    | period−1=9999                       |
| GTUPSR/GTDNSR | 0x6900/0x9600 | 0x6900/0x9600 | 四倍频 up/down 源                    |
| GTCR (0x2C)   | 0x00000001    | 0x00000001    | MD=0，CST=1                          |

### 6.3 硬件（待收尾）

1. 差分输入侧跨接 100~120Ω 终端，靠模块放置；编码器至模块全程双绞，不拆对。
2. 模块输出串 33~100Ω（置于模块端）；MCU 侧 P301/P302 对地 10~47pF。
3. 每根信号配独立地线并绞合，远离三相输出端子，缩短长度。
4. 模块电源就近 100nF+10µF 去耦，取自干净 3.3V。

## 7. 可复用结论

1. 换相角是编码器计数的函数。计数被污染不表现为测速抖动，而表现为力矩按 cosΔ 衰减；
   诊断入口是"电流给到了、力矩有没有出来"，不是环路参数。
2. τ_eff/τ_cmd 是首选观测量（J·α 阶跃/反相瞬态，或静态称重）；同转速稳态电流是低成本代理量。
3. 必须有不同源的交叉校核：三相电流电频率×PP 对比机械转速，或同一物理刻线回到同一 pos。
4. 配置检查项：GPT 输入噪声滤波默认关闭；单端编码器 + 长引线 + 贴近功率级时必须开启，
   且差分接收端必须做终端匹配。
