## 1. 摘要

三个拍型（仅电流环 / 加速度环 / 三环同拍）的 ISR 脉宽为 11.0 / 16.5 / 20.5 µs。将 HAL、
LTM_CTRL、LTM_FOC 三库统一开启 LTO 并统一架构参数后，同一测点降至 7.8 / 11.1 / 16.5 µs，
电流环拍减少 634 周期。

变化来源为跨库函数跳转被内联消除：调用闭包内跳转由 58 次降至 30 次。代价是
`control_tasks_run` 由 300 条指令膨胀至 1169 条，按拍型分段计时因此失去可比性。

按静态条数估，电流环拍执行约 950 条指令，CPI 由 2.3 降至 1.6，仍属取指受限。40kHz 载波
（周期 25µs）下 LTO 版三环拍占 66%，须重新分配工作才有可行性。

## 2. 测量口径

表中数值均含测量开销：`TEST_LOOP_TIME` 打开时每拍多两次 `R_IOPORT_PinWrite`（约 28 条指令）。

电流环拍内执行的模块：


| 类别 | 内容                                                                                                              |
| ---- | ----------------------------------------------------------------------------------------------------------------- |
| 测速 | 编码器锁存、PLL 更新（20kHz）、速度读取                                                                           |
| 保护 | 过流判定：三相任一越限即锁存错误码并封锁 PWM                                                                      |
| 上报 | `tasks_info` 的 Ia/Ib/Ic/Id/Iq                                                                                    |
| 控制 | 电角度换算与 1/1.5 拍延迟补偿、Clarke/Park、电流反馈 IIR、d/q 双 PI、dq 解耦前馈、矢量限幅、SVPWM、三相占空比写入 |

不在电流环拍内（应用上下文 `control_tasks_get()`）：母线过压/欠压、驱动器/电机过温扫描，
以及 pos/driver_temp/motor_temp/vbus 上报字段。

与外部数据对比时需说明：本表含测速、过流保护与电流上报，非裸 FOC。

## 4. 变化来源

### 4.1 跳转消除

"ADC 中断入口 → 三环"调用闭包内的函数跳转次数：


| 来源                  | 基线 | LTO |
| --------------------- | ---- | --- |
| LTM_CTRL              | 26   | 10  |
| LTM_HAL               | 13   | 10  |
| LTM_FOC               | 10   | 1   |
| libgcc（64 位除法等） | 9    | 9   |
| 合计                  | 58   | 30  |

按 14 周期/次折算为 392 周期；实测电流环拍减少 634 周期，差额来自 ISR 外壳内 FSP 调用
（`R_ADC_Read` 等）被内联，以及被调函数入口/出口的压栈弹栈。

### 4.2 内联副作用


| 函数                                 | 基线                | LTO                |
| ------------------------------------ | ------------------- | ------------------ |
| `control_tasks_run`                  | 300 条              | 1169 条            |
| `speed_loop_task`                    | 148 条              | 208 条             |
| `lt_scurve_update`                   | 554 条，独立函数    | 整体内联，符号消失 |
| `lt_pd_update`                       | 64 条，独立函数     | 整体内联           |
| `lt_speed_get` / `lt_pid_set_target` | 24 / 6 条，独立函数 | 整体内联           |

LTO 版位置段比基线多 277 周期，属段边界被内联挪动，非位置环变慢。

## 5. 复现条件

1. 三库架构参数必须一致。原 HAL 为 `-mcpu=cortex-m33 -mfpu=fpv5-sp-d16`，FOC 与例程为
   `-march=armv7e-m -mfpu=fpv4-sp-d16`；LTO 合并时报告
   `switch '-mcpu=cortex-m33' conflicts with switch '-march=armv7e-m+fpv5'`。
2. `%TEMP%` 不得含非 ASCII 字符。含中文用户名时 `lto-wrapper` 传递 `-fresolution=<路径>` 失败，
   报 `lto1.exe: fatal error: could not open symbol resolution file`；将 `TMP`/`TEMP` 指向纯 ASCII 目录。
3. `ar`/`ranlib` 报 `plugin needed to handle lto object` 属良性：静态库以 `--whole-archive`
   全量拉取，不依赖归档符号索引。
